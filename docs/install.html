01 · Instalar en Termux

Sigue los pasos en orden. Copia cada bloque y ejecútalo en Termux.

1

Actualizar paquetes

Actualiza el índice y los paquetes instalados.

pkg update && pkg upgrade
2

Instalar Git y Rust

Git descarga el repositorio; Rust y Cargo compilan el programa.

pkg install git rust
3

Comprobar versiones

La versión mínima del proyecto es Rust 1.75.

rustc --version cargo --version
4

Descargar el proyecto

git clone https://github.com/AmilcarGit/AmilcarCore-RS.git cd AmilcarCore-RS
5

Instalar AmilcarCore-RS

sh scripts/install.sh
6

Agregar el ejecutable al PATH

Hazlo si el instalador indica que la ruta no está configurada.

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc source ~/.bashrc
Instalación lista: ejecuta amilcar info para comprobar que el motor responde.

02 · Instalar en Linux

Selecciona los comandos correspondientes a tu distribución.

DEBIAN / UBUNTU

Herramientas base

sudo apt update sudo apt install -y git build-essential curl
FEDORA

Herramientas base

sudo dnf install -y git gcc
ARCH LINUX

Herramientas base

sudo pacman -Syu --needed git base-devel rust
RUST ESTABLE

Instalar con rustup

Si tu distribución no incluye Rust 1.75 o superior:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh . "$HOME/.cargo/env" rustup update stable

Clonar y compilar

git clone https://github.com/AmilcarGit/AmilcarCore-RS.git cd AmilcarCore-RS sh scripts/install.sh amilcar info

03 · Primeros comandos

›

04 · Solución de errores

cargo: command not found

Instala Rust/Cargo y vuelve a abrir la terminal. En Linux con rustup carga el entorno:

. "$HOME/.cargo/env"

Rust demasiado antiguo

Actualiza la toolchain estable y revisa su versión:

rustup update stable rustc --version

amilcar: command not found

Añade el directorio local al PATH:

export PATH="$HOME/.local/bin:$PATH"

La compilación se queda sin memoria

Cierra otras aplicaciones y repite el proceso. La compilación de Rust puede consumir memoria temporalmente.

Importante: la primera descarga del repositorio y de las dependencias de Cargo requiere conexión. El motor no necesita APIs externas para los comandos locales. Esta versión no incluye APK, interfaz gráfica ni binarios precompilados para Android.
